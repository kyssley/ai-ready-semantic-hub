# Changelog

## 0.1.0 — 2026-11-25

- Add typed semantic catalogs for models, relationships, metrics and terms.
- Add schema/reference/grain validation and composite-key join contracts.
- Add immutable SQLite snapshots, optimistic concurrency, publication and audit history.
- Add authenticated REST with viewer/editor/admin and entity visibility.
- Add constrained PostgreSQL/Hologres/DuckDB SQL compilation with currency and fanout guards.
- Add bilingual lexical retrieval, complete context packages and read-only stdio MCP.
- Add responsive web studio, YAML editor, CLI and conservative dbt manifest import.
- Add synthetic commerce examples, unit/integration tests and browser smoke script.
- Add bilingual READMEs, architecture/specification/deployment docs, MIT license and CI.

This release compiles SQL but does not execute warehouse queries. Live database compatibility and enterprise governance features are not implied.
